# Asteroid Curve Generator

A web-based application for generating mathematically accurate asteroid curves with customizable options and SVG export functionality.

## Features

### Curve Types
- **Astroid (4 cusps)**: Classic astroid curve using the parametric equations x = a·cos³(t), y = a·sin³(t)
- **Hypocycloid (Custom)**: Generalized hypocycloid with configurable number of cusps
- **Realistic Asteroid**: Randomized asteroid-like shapes for more organic appearances

### Configuration Options
- **Sharpness**: Control the number of cusps/points (3-20)
- **Size**: Adjust the overall size of the curve (50-280)
- **Randomness**: Add organic variation to the shape (0-100%)
- **Stroke Width**: Set the outline thickness (1-20)
- **Fill Color**: Choose the fill color
- **Stroke Color**: Choose the outline color
- **Display Mode**:
  - Filled: Show only the filled shape
  - Outline: Show only the outline
  - Both: Show both fill and outline
- **Show Center Point**: Display the center reference point

### Additional Features
- **Randomize**: Generate random configurations for experimentation
- **Regenerate**: Create a new variation with current settings
- **Download SVG**: Export the generated curve as a scalable SVG file

## Usage

1. Open `index.html` in a modern web browser
2. Select a curve type from the dropdown
3. Adjust the parameters using the sliders and color pickers
4. Click "Regenerate" to create a new curve with current settings
5. Click "Randomize" for random configurations
6. Click "Download SVG" to save your creation

## Mathematical Background

### Astroid
The astroid is a particular type of hypocycloid with 4 cusps, defined by:
- x(t) = a·cos³(t)
- y(t) = a·sin³(t)

Where 'a' is the size parameter and t ranges from 0 to 2π.

### Hypocycloid
A hypocycloid is a curve generated by tracing a point on a small circle rolling inside a larger circle:
- x(t) = (R-r)·cos(t) + d·cos((R-r)/r · t)
- y(t) = (R-r)·sin(t) - d·sin((R-r)/r · t)

Where R is the radius of the large circle, r is the radius of the small circle, and d is the distance from the center of the small circle.
