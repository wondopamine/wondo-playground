# Asteroid Curve Generator

A modern web application built with React, Vite, and ShadCN for generating mathematically accurate asteroid curves with real-time preview, accessible design, and SVG export functionality.

## Tech Stack

- **React 18** - Modern UI library
- **Vite** - Lightning-fast build tool
- **ShadCN** - Beautiful, accessible component library
- **Tailwind CSS** - Utility-first CSS framework
- **Radix UI** - Accessible UI primitives
- **Radix Colors** - Accessible color system

## Features

### Curve Types
- **Astroid (4 cusps)**: Classic astroid curve using parametric equations x = a·cos³(t), y = a·sin³(t)
- **Hypocycloid (Custom)**: Generalized hypocycloid with configurable number of cusps
- **Realistic Asteroid**: Randomized asteroid-like shapes for organic appearances

### Configuration Options
- **Sharpness**: Control curve sharpness/power (3-20) - affects all curve types
- **Size**: Adjust overall size (50-280)
- **Randomness**: Add organic variation (0-100%)
- **Corner Roundness**: Smooth corners with quadratic curves (0-100%)
- **Stroke Width**: Set outline thickness (1-20, default: 3)
- **Fill Color**: Choose from accessible Radix color palette
- **Stroke Color**: Choose from accessible Radix color palette
- **Display Mode**: Filled, Outline Only, or Both
- **Animation Speed**: Control drawing animation speed (10-100)
- **Show Center Point**: Display center reference

### Additional Features
- **Real-time Preview**: Instant updates as you adjust controls
- **Animate Drawing**: Watch the curve being drawn progressively
- **Randomize**: Generate random configurations
- **Regenerate**: Create new variation with current settings
- **Download SVG**: Export as scalable vector graphics

## Mathematical Background

### Astroid
The astroid is a particular type of hypocycloid with 4 cusps, defined by:
- x(t) = a·cos³(t)
- y(t) = a·sin³(t)

Where 'a' is the size parameter and t ranges from 0 to 2π.

### Hypocycloid
A hypocycloid is a curve generated by tracing a point on a small circle rolling inside a larger circle:
- x(t) = (R-r)·cos(t) + d·cos((R-r)/r · t)
- y(t) = (R-r)·sin(t) - d·sin((R-r)/r · t)

Where R is the radius of the large circle, r is the radius of the small circle, and d is the distance from the center of the small circle.
